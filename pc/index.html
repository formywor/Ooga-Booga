Your browser, with Nebula.

Nebula PC Preview connects a Chrome or Edge browser to your account for 30 days. Ultra can read pages, navigate approved sites, and prepare browser actions. D2 can inspect page text, visible controls, script references, runtime errors and observed network paths/statuses.

Download extension preview · 0.3.1

This preview is installed manually from its source folder. It is not a Chrome Web Store listing.

Set up on your computer

  1. Download the ZIP and extract it into a folder you can keep.
  2. Open chrome://extensions in Chrome, or edge://extensions in Edge. Turn on Developer mode, choose Load unpacked, and select the extracted nebula-pc-preview folder containing manifest.json.
  3. Open the public HTTPS tab you want Nebula to use, then open the Nebula PC extension from your browser toolbar. ScriptNovaa itself, browser settings, local addresses and password fields are blocked.
  4. Choose a computer name. By default, allow only the current website. Optionally allow other public HTTPS sites if your task needs navigation between services. Approve Chrome’s site-access prompt yourself.
  5. Click Connect this browser. Copy the pairing code shown by your own extension.
  6. On ScriptNovaa, sign in with a verified email, open PC controls next to the model picker, enter the code and review the 30-day consent. Never approve a pairing code supplied by someone else.
  7. Select Ultra or your invited D2 Preview, choose PC instead of Cloud, select your connected computer, and describe the task.

Update from the one-hour preview

Download the current ZIP and replace the files in your extension folder. Click Reload for Nebula PC in Chrome’s extension manager. Stop the old connection, refresh ScriptNovaa, then connect and approve a new 30-day pairing. An existing one-hour session is never extended automatically.

Choose your approval mode

Ask for Approval is the default. Pending actions appear in your chat with Approve this action and Decline. Approve for Me runs routine browser actions; sends and submissions still ask. Full Browser Access also permits ordinary email sends you requested. Payments, security changes and destructive actions still ask. Change the mode in PC controls and explicitly confirm its consent. The setting ends when the connection expires or you stop it; it does not grant new websites or desktop access.

More browser tools

Version 0.3 adds page readiness, bounded waits for visible text, text search, hover, dropdown selection and checkbox control. Existing tools include approved tabs, page inspection, navigation, clicking, typing, scrolling and keys. Chrome-generated permission prompts, passwords and browser settings remain yours to handle.

Use your phone

Sign in to the same Nebula account on your phone. Choose Ultra or D2, PC mode, and the connected computer. The computer must stay awake, online, and keep its browser running. The extension remains the executor; the phone does not need an extension. Newly requested website permissions may need approval on the computer.

Approvals and Stop

Every click, text entry and key press waits in PC controls. Review the actual page, target label and exact contents, then approve or decline that one action. After completion, choose Continue in chat. Reading, scrolling and navigation within approved access can run automatically.

For example: “Check the weather, then prepare an email draft.” Review recipients and text before approving a Send action. Review assignment work before approving submission.

You stay in control.

The extension badge and a page indicator show an active session. Stop from the extension, the page indicator, or PC controls on your phone. Stop cancels queued actions and blocks future work; it cannot undo completed actions. Sessions expire after 30 days and browser pairing credentials are kept in the extension’s trusted local storage so it can reconnect after browser restarts. Page text, traffic observations and action caches stay in browser-session memory. After a restart, existing tabs are not automatically shared: ask Nebula to open an approved website in a new tab, or reconnect from the tab you want to use.

What is shared

Approved page text, control labels and action results pass through your Nebula account and its AI service. Your signed-in pages can contain private information. PC conversations do not contribute to training or cross-chat memory. The extension does not read cookies, authentication headers, password fields, one-time codes, payment fields or network request/response bodies. Request paths and statuses may reflect your existing login; they do not prove public API access.

Preview limits

Browser tabs only. No desktop apps, operating-system control, arbitrary JavaScript, shell, local files, hidden browser sessions or remote uploads. No automatic exploit payloads or security bypasses. Some websites reject simulated input; inspect again to verify results. An interrupted action is not replayed automatically. Computer pairing is not required for ordinary Cloud mode.
