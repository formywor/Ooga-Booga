How this experiment works.

No custom ScriptNovaa executable is installed.

01 / CHECK

Verify before activation

The HTA checks that Microsoft Edge is installed before asking the API to activate your Z token.

02 / OPEN

Dedicated Edge profile

A separate Edge window opens with its own Project Z Modern profile. Your ordinary Edge profile and windows are not closed.

03 / CONTROL

Keep the HTA open

The HTA displays the timer, sends session heartbeats, monitors the dedicated browser, and closes it when the session finishes.

Choose your local-data mode.

Standard

Reuse a dedicated Project Z Modern profile so compatible website sign-ins and settings can remain between sessions.

Privacy

Create a session-specific profile and remove it after the session where Windows file locks permit. This is not Incognito.

Modern compatibility

Edge provides the current engine that a pure HTA cannot: modern JavaScript, WebGL, media APIs, Service Workers, and embeds.

Know before you start.

This is a direct browser connection, not a VPN or proxy. Websites see your normal public IP and apply their own terms and privacy policies.

Project Z Modern does not use Incognito and does not change computer-wide Edge policies. Microsoft Edge and Defender download protections stay active. Completely blocking every website-generated download requires an administrator-managed Edge policy and cannot be guaranteed by a standalone HTA.

A Z token starts when the API accepts it and cannot pause or resume. Closing the controller, closing the dedicated Edge window, expiry, revocation, or lost authorization finishes the token.

Use Project Z only on websites and networks you are authorized to access. The existing Project Z 0.1.5 remains available if you prefer its built-in Windows browsing component.
