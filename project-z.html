01 / EXTRACT

Keep the files together

Extract the complete ZIP. Open ProjectZ.hta, then choose Open Project Z. You can also run ProjectZ.exe directly. The HTA starts the companion; it is not the browser engine.

02 / CONNECT

Your registered computer

Existing Share Browser connections are checked automatically. New users generate one connection code on the Tokens page and enter it in Project Z. Only one computer is allowed per account.

03 / BROWSE

Choose a Z token

Select Project Z on the Tokens page, choose a duration, and paste the Z token into the app. When the session ends, browsing closes and the token screen returns.

Choose what stays on this computer.

Standard

Keep sign-ins and site data in a Project Z profile belonging to your account. Your regular Chrome and Edge profiles are not used.

Privacy

Use a new temporary profile for each session. Project Z removes that profile after closing it. This is not Incognito, a VPN, or a guarantee that every record is erased.

Search your way

Google, DuckDuckGo and Bing are search choices. All three use the same modern WebView2 browser engine and direct internet connection.

Know before you start.

This free release connects directly to websites. They can see your normal public IP. VPN and FAST connections are unavailable and never cost extra points.

A token starts when the API accepts it. Sessions cannot pause or resume. Closing the app, expiry, revocation, or losing authorization ends the token. Network interruptions are tolerated only within the current authorization window, at most 30 seconds.

Downloads, external applications, extensions, camera, microphone and location access are disabled in this first release. Some websites do not support embedded-browser sign-in. Pop-up links open in the same browsing view.

If the browser runtime is missing, install it from Microsoft's WebView2 page. Do not disable Windows security to run an unknown file. This beta is not code-signed.

Follow your school, workplace, and network rules. See our privacy information and terms. Need another connection code? Request one through Support.
