Add music.mp3 to the website root.

To rotate multiple songs, add each file to the music folder and add it to
playlist.json. The website selects one track for each UTC day. Only upload
music that ScriptNovaa owns or is licensed to use.

Add the public title, artist, album, release date, copyright notice,
description, and optional official HTTPS link to song-details.json. The src
must exactly match the same song in playlist.json.

Listeners can open Song info above the Daily Pick player. Repeat is optional,
off by default, and remembers the listener's choice in their browser.
