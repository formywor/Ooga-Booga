What is Share Browser?

A managed browser experience that starts Chrome or Microsoft Edge from a Windows HTA application.

01

Timed sessions

Users earn points, create a time-limited token, and start a session that is continuously validated by the ScriptNovaa API.

02

Separate experience

The launcher applies an approved browser configuration and keeps the Share Browser session separate from normal browsing.

03

User control

Users choose Chrome or Edge and a supported mode. Closing the session ends its token under the published rules.

Frequently asked questions

Short answers about ScriptNova and Share Browser.

Is ScriptNova the same as ScriptNovaa?

ScriptNovaa is the operator and website. ScriptNova is the product and developer identity. Both names refer to the same official platform family.

Is Share Browser a complete browser engine?

Share Browser is an HTA-based Windows browser launcher. It starts and manages supported Chrome or Microsoft Edge sessions rather than building a separate rendering engine.

Can I try Share Browser without downloading it?

Yes. The online demo provides a safe ten-minute preview of the interface. It is not a browsing proxy and cannot load arbitrary external websites.

Can developers build their own ScriptNova browser?

The ScriptNova Developer Program is in beta preview. Approved creators can apply to propose a branded browser or an approved domain partnership.
