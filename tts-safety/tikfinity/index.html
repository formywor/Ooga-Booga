This tab listens to TikFinity Desktop on this computer and sends chat messages to Nebula for filtering. It does not store your key or save clean comments.

Before you connect

  1. Have TikFinity Desktop running on this same computer and connect it to your LIVE. The browser dashboard alone does not expose the local Event API.
  2. Create a Nebula connection on the Live TTS Safety page, then copy its webhook key.
  3. Paste the key below and select Connect TikFinity. If Chrome asks to let ScriptNovaa connect to devices on your local network, allow it for the local TikFinity connection.
  4. Keep this tab open while streaming. The private voice overlay must also be added to OBS or TikTok LIVE Studio.

Not connected. Your key stays in this tab’s memory and is cleared when you disconnect or close the tab.

Only chat events are forwarded. Nebula receives the username and comment over HTTPS. TikFinity and the browser source do not receive your flagged-word history.

Test safely

After connecting, return to the setup page and send its harmless test message. Confirm it plays through your browser-source overlay before enabling the stream.

If the status says “Could not connect,” check that TikFinity Desktop is open on this PC, is connected to your live room, and that local-network access was allowed in Chrome.
