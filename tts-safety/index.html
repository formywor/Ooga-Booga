LIVE CHAT SAFETY

Let chat speak.
Keep the stream safe.

Nebula checks TikTok LIVE comments before they reach speech. Use TikFinity Desktop’s built-in Event API and a Nebula browser connector, then add the private speech overlay to OBS or LIVE Studio. No separate helper app to install.

Important setup detail

This uses Nebula’s speech overlay. Turn off TikFinity’s direct comment-to-speech action so unfiltered audio cannot play separately. TikFinity remains your event source.

01

Create your private connection

A private key connects TikFinity to your overlay. It is kept in this tab for refresh recovery and can be restored on another device when linked to a verified Nebula account. Keep it secret.

Sign in with a verified Nebula account before creating a connection to save it to your account. Restoring on another device creates a fresh webhook key; update that key in TikFinity.

Anyone with either value can use this connection. Don’t put them in a public post or share them with viewers. The key expires in 30 days.

02

Connect TikFinity

Use TikFinity Desktop’s local Event API. The browser Actions “Trigger Webhook” effect is for sending events to other services and cannot send Nebula the required secure JSON request.

  1. Open TikFinity Setup, enter your TikTok @username, and save it. Connect TikFinity while your LIVE is running.
  2. Keep the TikFinity Desktop app open on the same computer. The browser-only TikFinity dashboard does not provide its local Event API.
  3. Open the Nebula connector and paste your private webhook key. It stays in this browser tab’s memory and is sent only to Nebula’s API over HTTPS.
Open TikFinity connector

The connector listens only for chat events and forwards them to Nebula. Keep the connector tab open while streaming. Do not create a TikFinity “Trigger Webhook” action for this connection.

03

Add the Nebula voice overlay

Paste the private overlay URL above into OBS or LIVE Studio as a browser source. Allow audio and set the source size to match your canvas. It can be transparent and does not need to be visible. Then use the harmless test button in step 01 to confirm audio before going LIVE.

English dictionary words and common slang can be spoken. Known slurs and profanity stay blocked. Emoji and other languages follow your TTS settings. You can change strictness, add extra blocked phrases, choose an overlay voice, and customize the spoken moderation notice in Settings → TTS.

No word filter catches every context or evasion pattern. Keep TikTok’s own safeguards and a human moderator enabled.

What is stored?

Clean comments are not saved. For blocked comments, Nebula stores the detected term, username, time, event ID, and a one-way hash for up to 7 days so the creator can review what happened. The public overlay never receives the detected term. Anonymous connections receive 11,000 events per rolling 120 hours; a connection lasts 30 days.

Nebula+ AI review is optional and off by default. When enabled, every comment rejected by a content filter is sent to your selected eligible Nebula model; if it cannot return a clear verdict, Nebula tries other available models allowed for your account. D2 is never used. The comment is held while review runs and stays muted if no reviewer returns a clear safe verdict. Each model attempt uses your normal Nebula allowance. The model may allow ordinary slang or names, but it cannot override explicit blocked terms, your custom blocked phrases, or language, emoji, and link restrictions. TikFinity cooldown and duplicate-message drops are not sent for AI review.

Nebula+ review for filtered comments

Off by default. When on, the selected model runs first, followed by available account-eligible models if it times out, is busy, or returns no clear verdict. Nebula waits up to 8 seconds per model. Comments stay muted if review cannot finish safely. Each attempt uses your normal Nebula allowance. TikFinity duplicate and cooldown drops are not sent for review. Filtered comments are shared with the model service to make this decision; D2 is never used.
